## Architecture Overview

Our application follows a clean, layered architecture that separates concerns:

```
Controller → Service → Repository → Model
```

Each layer has a specific responsibility:

- **Controllers**: Handle HTTP requests/responses and input validation
- **Services**: Contain business logic and orchestrate operations
- **Repositories**: Manage data access and database operations
- **Models**: Represent database entities

This separation allows for better testability, maintainability, and scalability.

## Base Interfaces

### RepositoryInterface

This is the foundation interface that all repository interfaces extend:

```php
<?php

namespace App\Repositories\Contracts;

interface RepositoryInterface
{
    public function all(array $columns = ['*']);
    public function find($id, array $columns = ['*']);
    public function findBy(string $field, $value, array $columns = ['*']);
    public function findWhere(array $where, array $columns = ['*']);
    public function create(array $attributes);
    public function update(array $attributes, $id);
    public function delete($id);
    public function with($relations);
    public function setFilters(array $filters);
    public function count();
    public function get();
}
```

### ServiceInterface

Base interface that all service interfaces extend:

```php

namespace App\Services\Contracts;
```

## Base Classes

### BaseRepository

The `BaseRepository` class implements the `RepositoryInterface` and provides common functionality that all repositories share:

```php
<?php

namespace App\Repositories;

use App\Repositories\Contracts\RepositoryInterface;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Support\Collection;

abstract class BaseRepository implements RepositoryInterface
{
    protected $entity;
    protected $relations = [];
    protected $filters = [];

    public function all(array $columns = ['*'])
    {
        return $this->entity->all($columns);
    }

    public function find($id, array $columns = ['*'])
    {
        return $this->entity->find($id, $columns);
    }

    public function findBy(string $field, $value, array $columns = ['*'])
    {
        return $this->entity->where($field, $value)->first($columns);
    }

    public function findWhere(array $where, array $columns = ['*'])
    {
        $query = $this->entity->query();
        
        foreach ($where as $field => $value) {
            $query->where($field, $value);
        }
        
        return $query->get($columns);
    }

    public function create(array $attributes)
    {
        return $this->entity->create($attributes);
    }

    public function update(array $attributes, $id)
    {
        $record = $this->find($id);
        
        if (!$record) {
            return false;
        }
        
        $record->update($attributes);
        return $record;
    }

    public function delete($id)
    {
        $record = $this->find($id);
        
        if (!$record) {
            return false;
        }
        
        return $record->delete();
    }

    public function with($relations)
    {
        $this->relations = is_array($relations) ? $relations : [$relations];
        return $this;
    }

    public function setFilters(array $filters)
    {
        $this->filters = $filters;
        return $this;
    }

    public function count()
    {
        return $this->applyFilters()->count();
    }

    public function get()
    {
        $query = $this->applyFilters();
        
        if (!empty($this->relations)) {
            $query = $query->with($this->relations);
        }
        
        return $query->get();
    }

    protected function applyFilters()
    {
        $query = $this->entity->query();
        
        foreach ($this->filters as $filter) {
            if (!isset($filter['key']) || !isset($filter['value']) || !isset($filter['type'])) {
                continue;
            }
            
            $key = $filter['key'];
            $value = $filter['value'];
            $type = $filter['type'];
            
            switch ($type) {
                case 'string':
                    $query->where($key, 'LIKE', "%{$value}%");
                    break;
                case 'exact_string':
                    $query->where($key, $value);
                    break;
                case 'array':
                    $query->whereIn($key, $value);
                    break;
                case 'number':
                    $query->where($key, $value);
                    break;
                case 'bool':
                    $query->where($key, (bool) $value);
                    break;
                case 'date':
                    $query->whereDate($key, $value);
                    break;
                case 'datefrom':
                    $query->whereDate($key, '>=', $value);
                    break;
                case 'dateto':
                    $query->whereDate($key, '<=', $value);
                    break;
                case 'between':
                    if (is_array($value) && count($value) === 2) {
                        $query->whereBetween($key, $value);
                    }
                    break;
                case 'isNull':
                    $query->whereNull($key);
                    break;
                case 'isNotNull':
                    $query->whereNotNull($key);
                    break;
            }
        }
        
        return $query;
    }
}
```

### BaseService

The `BaseService` class implements the `ServiceInterface` and delegates most operations to its repository:

```php
<?php

namespace App\Services;

use App\Repositories\Contracts\RepositoryInterface;
use App\Services\Contracts\ServiceInterface;

abstract class BaseService implements ServiceInterface
{
    protected $repository;
    
    public function __construct(RepositoryInterface $repository)
    {
        $this->repository = $repository;
    }

    public function all()
    {
        return $this->repository->all();
    }

    public function find($id)
    {
        return $this->repository->find($id);
    }

    public function findBy(string $field, $value)
    {
        return $this->repository->findBy($field, $value);
    }

    public function findWhere(array $where)
    {
        return $this->repository->findWhere($where);
    }

    public function create(array $data)
    {
        return $this->repository->create($data);
    }

    public function update(array $data, $id)
    {
        return $this->repository->update($data, $id);
    }

    public function delete($id)
    {
        return $this->repository->delete($id);
    }

    public function with($relations)
    {
        $this->repository->with($relations);
        return $this;
    }

    public function setFilters(array $filters)
    {
        $this->repository->setFilters($filters);
        return $this;
    }

    public function count()
    {
        return $this->repository->count();
    }

    public function get()
    {
        return $this->repository->get();
    }
}
```

## Repository Implementation

After generating the repository interface and class using the `make:resources` command, the implementation looks like:

### Model-Specific Interface

```php
<?php

namespace App\Repositories\Contracts;

use App\Repositories\Contracts\RepositoryInterface;

interface ProductRepositoryInterface extends RepositoryInterface
{
    // Add model-specific repository methods here
    public function findByCategory($categoryId);
    public function findPopularProducts($limit = 10);
}
```

### Concrete Repository

```php
<?php

namespace App\Repositories\Product;

use App\Models\Product;
use App\Repositories\BaseRepository;
use App\Repositories\Contracts\ProductRepositoryInterface;

class ProductRepository extends BaseRepository implements ProductRepositoryInterface
{
    protected $entity;

    public function __construct(Product $model)
    {
        $this->entity = $model;
    }

    public function findByCategory($categoryId)
    {
        return $this->entity->where('category_id', $categoryId)->get();
    }

    public function findPopularProducts($limit = 10)
    {
        return $this->entity->orderBy('views', 'desc')->limit($limit)->get();
    }
}
```

## Service Implementation

### Model-Specific Service Interface

```php
<?php

namespace App\Services\Contracts;

use App\Services\Contracts\ServiceInterface;

interface ProductServiceInterface extends ServiceInterface
{
    // Add model-specific service methods here
    public function getProductsByCategory($categoryId);
    public function getPopularProducts($limit = 10);
    public function increaseProductView($productId);
}
```

### Concrete Service

```php
<?php

namespace App\Services\Product;

use App\Repositories\Contracts\ProductRepositoryInterface;
use App\Services\BaseService;
use App\Services\Contracts\ProductServiceInterface;

class ProductService extends BaseService implements ProductServiceInterface
{
    protected $repository;

    public function __construct(ProductRepositoryInterface $repository)
    {
        parent::__construct($repository);
    }

    public function getProductsByCategory($categoryId)
    {
        return $this->repository->findByCategory($categoryId);
    }

    public function getPopularProducts($limit = 10)
    {
        return $this->repository->findPopularProducts($limit);
    }

    public function increaseProductView($productId)
    {
        $product = $this->repository->find($productId);
        
        if (!$product) {
            return false;
        }
        
        $product->views += 1;
        $product->save();
        
        return $product;
    }
}
```

## Dependency Injection

To make the services and repositories available through dependency injection, register them in a service provider:

```php
<?php

namespace App\Providers;

use Illuminate\Support\ServiceProvider;

class RepositoryServiceProvider extends ServiceProvider
{
    /**
     * Register services.
     *
     * @return void
     */
    public function register()
    {
        // Repositories
        $this->app->bind(
            \App\Repositories\Contracts\ProductRepositoryInterface::class,
            \App\Repositories\Product\ProductRepository::class
        );

        // Services
        $this->app->bind(
            \App\Services\Contracts\ProductServiceInterface::class,
            \App\Services\Product\ProductService::class
        );
    }
}
```

Don't forget to register this provider in `config/app.php`:

```php
'providers' => [
    // ...
    App\Providers\RepositoryServiceProvider::class,
],
```

## Advanced Usage

### Custom Filtering

The base repository includes a flexible filtering system. Here's how to use it:

```php
// In a controller:
public function index(ListProductRequest $request)
{
    $filters = $request->validated()['filters'] ?? [];
    $products = $this->productService->setFilters($filters)->get();
    
    return response()->json(['data' => $products]);
}
```

Filter example:

```json
{
    "filters": [
        {
            "key": "name",
            "value": "Laptop",
            "type": "string"
        },
        {
            "key": "price",
            "value": [100, 1000],
            "type": "between"
        },
        {
            "key": "category_id",
            "value": [1, 2, 3],
            "type": "array"
        }
    ]
}
```

### Extending Repositories with Criteria Pattern

For more complex queries, implement the criteria pattern:

```php
<?php

namespace App\Repositories\Criteria;

use App\Repositories\Criteria\CriteriaInterface;

class LatestProductsCriteria implements CriteriaInterface
{
    public function apply($model)
    {
        return $model->orderBy('created_at', 'desc');
    }
}
```

Then in your repository:

```php
public function getLatestProducts()
{
    $criteria = new LatestProductsCriteria();
    $query = $criteria->apply($this->entity->query());
    
    return $query->limit(5)->get();
}
```

## Best Practices

1. **Keep Interfaces Focused**: Each interface should have a single responsibility. Don't add unrelated methods to existing interfaces.

2. **Move Business Logic to Services**: Repositories should only handle data access. All business logic should be in services.

3. **Use Type Hints**: Always use type hints for method parameters and return types to improve code clarity and catch errors early.

4. **Repository Method Naming**: Use consistent naming conventions:
   - `find*` for retrieving single records
   - `get*` for retrieving multiple records
   - `create*` for creating records
   - `update*` for updating records
   - `delete*` for deleting records

5. **Service Method Naming**: Services should use domain-specific naming that describes the business operation being performed.

6. **Use Transactions**: For operations that modify multiple records, use database transactions in your service methods:

   ```php
   public function transferFunds($fromAccountId, $toAccountId, $amount)
   {
       return DB::transaction(function () use ($fromAccountId, $toAccountId, $amount) {
           $fromAccount = $this->accountRepository->find($fromAccountId);
           $toAccount = $this->accountRepository->find($toAccountId);
           
           // Perform transfer logic here
           
           return $fromAccount;
       });
   }
   ```

7. **Avoid N+1 Query Problems**: Always use eager loading when you know you'll need related models:

   ```php
   public function getProductsWithCategories()
   {
       return $this->repository->with('category')->get();
   }
   ```

8. **Add Custom Exceptions**: Create domain-specific exceptions to provide better error handling:

   ```php
   class InsufficientFundsException extends \Exception {}
   
   // In your service:
   if ($account->balance < $amount) {
       throw new InsufficientFundsException("Not enough funds in account");
   }
   ```

9. **Test Each Layer Separately**: Write unit tests for repositories, services, and controllers separately to ensure each component works correctly in isolation.
